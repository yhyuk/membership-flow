ASSIGNMENT 해석 결정 / 보수적 선택:
  1. 이벤트 모델링 — ASSIGNMENT는 "변경할 구독 상태"를 요청에 받지만 정책 입력을
     단일 enum으로 표현하기 위해 (action, targetState) 4종으로 분해.
     별도 dispatcher 없이 Policy가 enum 룩업으로 결정적 결과를 산출.
  2. NONE → UNSUBSCRIBE_NONE — handoff §7 결정대로 거부 (해석 2).
  3. BASIC + SUBSCRIBE_BASIC — 매트릭스 명시 없음 → 동일 상태 멱등 거부 (handoff §3.5).
  4. PREMIUM + SUBSCRIBE_PREMIUM — 동일 사유 멱등 거부.
  5. BASIC + UNSUBSCRIBE_BASIC — BASIC→BASIC은 의미 없는 요청 → 거부.
  6. channels UNIQUE(member_id, channel_id) — ASSIGNMENT "구독/해지 여러 번 가능"은
     동일 채널 행을 변경하는 방식으로 해석. history 테이블이 전이 흔적 보존.
  7. event_type enum 컬럼은 ActionType(SUBSCRIBE/UNSUBSCRIBE) 2값만 저장.
     details(SUBSCRIBE_BASIC vs SUBSCRIBE_PREMIUM)은 next_state로 복원 가능.
